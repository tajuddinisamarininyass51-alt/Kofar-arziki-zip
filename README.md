# Kofaraziki Data

A comprehensive fintech and mobile utility payment platform designed to simplify digital transactions and enable users to earn through referrals.

## 📱 Features

### Core Services
- **Data Plans** - Purchase mobile data packages
- **Airtime** - Top-up phone credit
- **Cable Subscriptions** - TV service subscriptions
- **Electricity Bills** - Utility bill payments
- **Data Card** - Additional data purchase options
- **Airtime to Cash** - Convert unused airtime to money
- **Education Pins** - Educational vouchers
- **Recharge Pins** - Prepaid vouchers

### User Features
- **Smart Earner Package** - Earn money through referrals
- **Wallet System** - Fund and manage your account
- **Balance Tracking** - Real-time account balance
- **Transaction History** - View all transactions
- **Affiliate Program** - Generate affiliate links and earn commissions
- **Referral Bonuses** - Earn from referrals
- **Account Limits Management** - Control transaction limits
- **Support System** - Contact support and log complaints

## 💰 Pricing & Charges
- **Transaction Charge:** 1% (capped at ₦50)
- **Payment Method:** Palmpay integration

## 👤 User Account
- Account Balance display
- Referral Bonus tracking
- Virtual account management
- Account upgrade options
- Profile customization
- Settings and preferences
