# Deployment Guide\n\n## Pre-Deployment Checklist\n\n- [ ] All tests passing\n- [ ] Code reviewed and approved\n- [ ] Environment variables configured\n- [ ] Database migrations ready\n- [ ] Documentation updated\n- [ ] Version number updated\n- [ ] Changelog updated\n\n## Environment Setup\n\n### Development\n```bash\nNODE_ENV=development\nDEBUG=true\n```\n\n### Staging\n```bash\nNODE_ENV=staging\nDEBUG=false\n```\n\n### Production\n```bash\nNODE_ENV=production\nDEBUG=false\n```\n\n## Deployment Steps\n\n### 1. Staging Deployment\n\n```bash\n# Pull latest code\ngit pull origin develop\n\n# Install dependencies\nnpm install\n\n# Run database migrations\nnpm run migrate:up\n\n# Run tests\nnpm test\n\n# Build\nnpm run build\n\n# Start server\nnpm start\n```\n\n### 2. Production Deployment\n\n```bash\n# Pull latest code from main branch\ngit pull origin main\n\n# Install dependencies\nnpm install --production\n\n# Run database migrations\nnpm run migrate:up\n\n# Build\nnpm run build\n\n# Start with PM2\npm2 start ecosystem.config.js --env production\n```\n\n## Using PM2\n\n### Install PM2\n```bash\nnpm install -g pm2\n```\n\n### Start Application\n```bash\npm2 start app.js --name kofaraziki\n```\n\n### Manage Application\n```bash\npm2 logs                 # View logs\npm2 restart kofaraziki   # Restart app\npm2 stop kofaraziki      # Stop app\npm2 delete kofaraziki    # Remove app\npm2 save                 # Save startup script\n```\n\n## Docker Deployment\n\n### Build Docker Image\n```bash\ndocker build -t kofaraziki:latest .\n```\n\n### Run Container\n```bash\ndocker run -p 3000:3000 \\\n  -e NODE_ENV=production \\\n  -e DATABASE_URL=your_db_url \\\n  kofaraziki:latest\n```\n\n## Monitoring\n\n### Check Server Status\n```bash\npm2 status\npm2 monit\n```\n\n### View Logs\n```bash\npm2 logs kofaraziki\npm2 logs kofaraziki --err\npm2 logs kofaraziki --out\n```\n\n## Health Checks\n\n### API Health Endpoint\n```bash\nGET /health\n```\n\nShould return:\n```json\n{\n  \"status\": \"ok\",\n  \"timestamp\": \"2026-09-05T12:00:00Z\",\n  \"uptime\": 12345,\n  \"version\": \"1.0.0\"\n}\n```\n\n---\n*Last Updated: 2026-09-05*\n
